# 重建窗口 delta 复走 —— 设计

**Status:** 草稿待裁（2026-10-05）：D1、D2 两个决策点未拍；成对 plan 同名。

**本对一件事：给同宽换模型的就地重建补上「翻转后的 delta 复走」，让「章=真相」成立。**

来源：`2026-10-04-vector-reembed-and-embed-identity-guard-design.md` §2.3 残余注记（待拍转立项），落法已裁=独立小对（2026-10-05 他拍甲）。与孤儿向量清扫对（`2026-10-04-rag-orphan-vector-sweep-design.md`）互补不重叠：清扫判「业务行不存在」删无主点；本对修「业务行都在、向量空间错了」的活文档。

## 1. 问题（机制与证据链）

同宽换模型保存（D3）的就地重建是**一遍过行走**：`rag_reembed._run` 逐库 `reindex_kb` 重嵌现存行，全部走完才原子翻转配置。两个事实叠出洞：

1. **窗口里完成的新文档由 worker 按被 hold 的旧配置嵌入**——hold 是有意的（窗口里查询侧与新写入在旧空间自洽），代价是这些文档的向量落在旧空间。
2. **行走不回头**——行落在游标后面的文档再也不被重嵌；而翻转后 D2 盖章声明「本库向量=新空间」，把它们一起谎报。

后果：那篇文档的切片**永久静默漏检**（旧空间向量 vs 新空间查询 cos≈0——与本对源头根因「322 条 stale 向量」同类病、换个产生者）；D2 章是假声明；D4 看不见（身份与配置一致，失配不响）。

- 触发面：每遍重建窗口（A4 实测 4.5 / 3.75 分钟）内有文档完成入库；触发后永久、静默。
- 现成先例：宽度迁移通道（`dimension_migration.migrate_collections`）早有同款二遍（`include_non_terminal=True`）专门收「迁移窗口里没跑完的文档」——D3 新写时没抄这半，属遗漏非裁定（2026-10-04 Task 2 发现，spec §2.3 已记账）。
- 活体证据：A4 看守日志两遍同序（库逐个盖章 1→2→4→5 期间文件恒 hold 旧值、5/5 才翻）——顺带可见中间态正是 D4 短暂失配窗口。

## 2. 方案

翻转后每库补走一遍 `reindex_kb(..., include_non_terminal=True)`：配置已切新模型，此后 worker 的新写入都是新空间；delta 复走把**翻转前写入、主行走没覆盖**的行补进新空间。动作与宽度通道的二遍同构，`reindex` 现成参数（Task 0 核实签名与语义）。

窗口的单向门是翻转：delta **必须**在翻转后跑才有封闭的目标集（翻转前跑，行还在不断到达）。因此盖章时序也要跟着动（D2）。

## 3. 决策点（待裁 2026-10-05）

- **D1 delta 复走的范围 = 待拍。甲（推荐）：翻转后每库一遍 delta**——洞从「整个行走窗口」缩到「单文档的嵌入时延」（宽度通道同款姿态、同款残余）。乙：delta 后再复核「delta 期间新完成的文档」直到空集（收敛环，彻底关闭但多一层循环与判定）。未选：不做（洞保持现状）。
- **D2 盖章归属 = 待拍。乙（推荐）：章改由 delta 走完才盖**——主行走带 `stamp=False`（`reindex_kb` 参数化、默认不变），delta 完整走完才写身份。失败面由此诚实：**delta 失败 ⇒ 章留旧值/NULL ⇒ D4 失配可见**、重跑即愈。甲：保持现状（主行走照盖、delta 失败仅记日志）——失败后章仍是假声明且无人看得见，与本对目的相反。

## 4. 硬约束

- 不动 worker 写序、不动 hold/flip 语义、不动宽度通道（`migrate_collections` 及其二遍零改动）。
- `reindex_kb` 默认行为零变化（参数化 opt-in）；查询路径零改动、不拦截。
- 失败如实：delta 失败记日志 + 状态 `failed`，不翻回、不遮掩。
- 尾部残余（单文档嵌入时延）登记不做收敛环（与宽度通道同口径），除非 D1 拍乙。

## 5. 验收

1. 单测（D2=乙）：主行走完成不写身份；delta 完整走完才写（=当前指纹）。
2. 单测：模拟窗口文档（行落在主行走游标后）⇒ delta 把它补进新空间；cos 抽验复常。
3. 单测：delta 失败 ⇒ 身份留旧值/NULL（D4 判词可见失配或无主张），重跑修复。
4. 门禁：knowledge 面（环境红按既有账）+ ruff check/format 双净。

## 6. 非目标

- 不做收敛环尾部关闭（D1 未拍乙前）；
- 不改 D2 身份编码/写入两处的既有规则（`reindex_kb` 完整性闸、worker 首件闸原样）；
- 不做 D4 的观测面扩展（失配提示仍是 recall-test 一处）；
- 与物化默认键小补丁（rag_config 写路径，另案）无关。
